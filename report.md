# Документация проекта по предсказанию исходов матчей в компьютерной игре Dota 2

## CI-CD процесс

**Используемые github-actions**

В проекте используется два флоу:

- Линтеры для того, чтобы отслеживать стайлкод сразу при создании PR. При обновлении кода в PR линтеры снова запускаются
- Деплой скрипт - после того, как происходит merge PR'а - происходит деплой функций на AWS. При merge в ветку main все AWS объекты имеют префикс prd-\*, при merge в остальные ветки используется префикс dev-\*

## Кодовая база серверной части

Вся серверная часть лежит в branch dev/feature/service в директории lambdas

**Описание структуры файлов**

Внутри директории lambdas для каждой ручки предусмотрена своя директория:

- FitModel
- GetModel
- Predict
- SetModel

Внутри директории ручки лежит три файла:

 - lambda_function.py - файл с python кодом, который выполняется на сервере
 - reuirements.txt - версии библиотек для кода
 - Dockerfile - докер файл, который используется при сборке и деплое функционала на сервер

## Streamlit приложение

Это веб-приложение, разработанное с использованием Streamlit, которое объединяет несколько модулей для работы с данными, обучения моделей, получения инференса и сравнения экспериментов. Приложение позволяет:

- **Загружать датасеты:** Пользователь может загрузить CSV-файл, который сохраняется в `st.session_state` для дальнейшего использования.
- **Проводить EDA (Exploratory Data Analysis):** Выполняется предварительный анализ данных с помощью различных графиков (гистограммы, корреляционная матрица, распределения по группам и парные графики).
- **Обучать модели:** Доступны два режима:
  - **Обучение с нуля:** Пользователь выбирает классификатор и задаёт гиперпараметры. 
  - **Дообучение существующей модели:** Пользователь выбирает одну из сохранённых моделей для дообучения. В этом режиме происходит вызов внешнего API для дообучения модели.
- **Отображать информацию о модели:** Выводятся метрики, гиперпараметры, матрица ошибок и кривая обучения для выбранной модели.
- **Выполнять инференс:** Пользователь может загрузить CSV с данными для предсказаний, выбрать модель для инференса и получить предсказания через вызов API. Результаты можно скачать в виде CSV-файла.
- **Сравнивать эксперименты:** Возможность визуально сравнить кривые обучения (валидационные показатели) нескольких экспериментов на одном графике.

## Документация API ручек сервера

### POST `/dev/dev-fitmodel`

**Summary:** Обучение новой или существующей модели

**Description:**  
Принимает несколько параметров:  
- Если вы хотите сделать fit на существующей модели, то нужно взять параметр `model_name`.  
- Если вы хотите сделать fit на новой модели, то нужно взять параметры:
  - `new_model_name` - название новой модели  
  - `model_type` - принимает значение `"LogisticRegression"` или `"SGDClassifier"` - тип модели  
  - `model_params` - параметры новой модели  

Выбранная модель обучается и сохраняется для дальнейшего использования на s3 bucket.

**Method:** POST

---

### POST `/dev/dev-setmodel`

**Summary:** Задание главной модели

**Description:**  
На вход принимает параметр `model_name`. В случае если такая модель есть - она устанавливается как основная в базе данных.

**Method:** POST

---

### GET `/dev/dev-predict`

**Summary:** Предсказание

**Description:**  
Принимает на вход два параметра:  
- `model_name` - на какой модели нужно делать предсказание  
- `data_path` - путь к файлу с данными для предсказаний на s3 bucket  

Возвращает JSON с результатом предсказаний в виде списка со значениями 0/1 - выиграли Radiant или нет.

**Method:** GET

---

### GET `/dev/dev-getmodel`

**Summary:** Получение информации о моделях

**Description:**  
Не принимает параметров. Возвращает в виде списка информацию о существующих моделях.

**Method:** GET
